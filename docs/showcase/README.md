## 公开图片如何处理机密内容

- 金额、百分比、预算、主副行、图标及其他经营数据全部覆盖；空值、负数等原始分布也不保留。
- 人名、公司身份、项目及门店名称、报告期间、业务状态、数量和实际条件颜色一并覆盖或裁掉。V41 通用状态图例只说明样式，不保留真实项目状态。
- 使用与原始像素无关的不透明马赛克，直接写入 RGB PNG。没有透明遮罩、可移除图层或仅靠模糊处理的文字。
- 源表区域重绘后不含原始水印。导出的 PNG 仅含图像编码块，不含 EXIF、文本、网址或来源路径元数据。
- 公开仓库没有新增原始截图、原 V41 HTML/ZIP、真实报表 JSON、原文链接、截图处理底稿或登录信息。

## 可运行的实例数据

运行和交接使用仓库里的 [虚构数据](../../examples/synthetic-report.json)，不要从马赛克猜测或还原数值。

在仓库根目录运行：

```powershell
npm.cmd test
npm.cmd run demo
```

随后打开新生成的 `outputs/synthetic-monthly-vNNN/index.html`，即可体验当前 Skill 模板的交互；`report.json` 和 `handoff.json` 保存在同一版本目录。这个虚构示例用于演示 Skill，不承诺与历史 V41 逐像素一致。

开始处理自己的材料前，阅读 [交接指南](../../TEAM_HANDOFF.md)，并从 [PROMPTS.md](../../PROMPTS.md) 复制调用文本。
