# 默认投屏模板

这些是当前协作最终确认的默认值。特定月份、店名和原始金额不属于模板。视觉发生自然语言调整时由代理生成本次覆盖配置，用户不必手改文件。

| 项目 | 默认 |
| --- | --- |
| 页面 | V41 商务蓝灰、渐变表头/卡片/工具区、轻边框阴影；保留默认字体与两层框架 |
| 顶栏 | 在文档顶部，随页面自然滚走，不吸顶 |
| KPI | 一级与二级都有流水蓝、收入紫、发行毛利橙、项目毛利绿四卡；缺同口径数据保留 -- |
| KPI 字体 | 标题 15px、数值 23px、补充说明 12px；单位从来源确认，不强制把外币写成人民币 |
| 层级 | 店总览和店内项目两层；展开项目不进入第三层 |
| 一级 | 店名/游戏项目组左对齐，其他列及第二小行居中 |
| 一级标题与达成标签 | 游戏项目组、达成情况标题约 19px；达成/不达成用 V41 绿/红描边浅底标签，约 17px |
| 一级冻结 | 两行列头、名称和达成情况列；相交处背景不透底 |
| 实际区 | 上行近白，下行浅蓝；图标的形状和颜色按源证据分别绑定主副值 |
| 累计区 | 上行近白，下行浅绿；主副行都支持源图标，其后数字同色；一级下行预算不加前缀 |
| 期间边界 | 一级与二级实际月、累计月之间都有浅色竖线，默认 3px；表头及两小行贯通 |
| 项目边界 | 两小行只用底色区分，大行间浅色细横线 |
| 二级 | 游戏项目名称 rowspan=2，垂直居中；固定名称列及其单位表头，状态列随横滚 |
| 二级颜色与顺序 | 新在营淡黄 → 在营商务蓝 → 其他；在研/未立项淡紫、终止淡红，同状态连续且保留源顺序，合计最后 |
| 操作 | 一级展开全部/收起全部共用按钮；每个店都有方框加减按钮，包括单项目/没有同口径子行的店。默认收起；一级无全部字段入口 |
| 二级字段切换 | 默认原表可见行列；全部字段同时展开已读取的源隐藏行和列，按钮放表框右上角，精简字段恢复默认；不是读取完成状态 |
| 月度副行标题 | 年月从本期 period 得到：某年某月实际 / 下行：月度达成率。费毛比副行仍按 source secondaryKind 显示原表差额，不强制转成达成率 |
| 冗余文字 | 不恢复飞书校准、表内项目数、越低越好、项目名称的小计后缀、奖金长注释、排序模式切换 |
| 缺失值 | --；数字零仍显示 0，负号保留 |

数据字约 17px、副行约 14px、指标表头约 14px。名称列按最长名称与缩进计算，约 170px 起，允许有界扩展和长名换行，不能让字段挤进冻结列。表格占页面全宽，可视高度随屏幕增加；实际能多看多少店要按 DOM 量测，不以 max-height 变大代替实际结果。

“精简”只指还原源默认可见性，不是挑选核心指标。原表本来可见的毛利、毛利2、项目净利、流水、人力投入度等都默认展示。隐藏状态未知先记录未知，不宣称原表隐藏。名称去“小计”只影响显示，不改原文、ID、来源或汇总角色。第一层展开不得泄漏源隐藏项目。

红/绿/黄图标和后面数字使用同色，包括二级累计副行；未读图标用待核状态，不按正负或 >=100% 猜色。金额负号保留，即使其源图标为绿也跟绿。长百分比预留完整数值和图标宽度，不能遮挡首位；来源位置与核对日志放 report/handoff/审计文档，不堆在产品表格中。

不同尺寸：优先 1920x1080，其次 1440/1280；手机端允许表格独立横滚，指标卡换行。字号不随 vw 缩放，内容必须不重叠。

`assets/defaults.json` 是稳定样式参数；表格主副行含义属于每期字段配置，不能只按颜色推断。
