# 验收

输入契约：期间有效，来源清单完整，表格和主体 ID 唯一，所有列槽位显式存在；主、副数值有各自血缘；unreadable/unresolved 必须列出，不得判为完整通过。

数据：从独立源字段清单查漏，再核对公司及每店 KPI、一级总表、一级展开项目、所有二级分表。逐店检查主副配对，特别远端对照列。分列应有/映射字段、主值、副值、源空白/无列证据、隐藏行列、图标、当次重读/既有快照及未确认数，不能只用模型已有字段当分母。缺原始来源验证不得称完整财务通过。

页面：实际在 1920x1080、1280x800、390x844 检查。截图包括总览、展开、二级、最大横滚和纵滚相交区。检查表头和固定列落点及 elementFromPoint 遮挡，不仅断言 position:sticky；检查文字 Range 边界与单元格边界，不仅看 scrollWidth。

交互：默认收起，一级无全部字段按钮；单项目也有展开框。展开全部后源隐藏子行仍隐藏。二级精简模式保留所有源可见列（测试可见毛利/毛利2且 optional=true），全部字段同时显示已读取隐藏行列，切回恢复。点店/返回正常，项目不进入第三层；排序保留源路径；两层四张卡缺同口径值显示 --。备注等已有交互在增量改版中保持。

颜色：检查状态分组连续、生命周期底色、项目间横线、实际与累计浅色竖线、加大标题/达成标签和渐变风格。主值/副值各自图标与数字同色，不按正负推断。测试负主值带绿标、正副值带红旗、长百分比完整位数，读 DOM 文本和 Range 边界验证不遮挡。月度副行标题正确，费毛比差额语义仍保留。

产物：构建前后基线 hash 一致，输出目录新增、不覆盖；重开生成 HTML 检查，避免只看内存页面。验证使用传入路径，不能写死用户目录或 Edge 路径。记录检查命令、截图、源码 hash、已核对覆盖范围和剩余问题。
